# 🍳 Cocina en Crisis

> El primer producto de **Luna Studio**.

Una aplicación móvil creada con **React Native + Expo** diseñada para ayudar a las personas a cocinar con los ingredientes que ya tienen en casa y cuidar su presupuesto.

---

# ✨ Objetivo

Muchas personas tienen ingredientes en casa pero no saben qué cocinar.

**Cocina en Crisis** analiza los ingredientes disponibles y recomienda recetas económicas, mostrando:

- Compatibilidad con tus ingredientes.
- Costo aproximado.
- Tiempo de preparación.
- Lista inteligente de compras.
- Seguimiento de ingredientes comprados.
- Favoritos.
- Modo paso a paso para cocinar.

---
